# Overview

> Last updated: 2026-05-06  
> Version: 1.0.0

## App Name and Purpose
**AL-SAQI (نظام الساقي)** is a comprehensive and secure professional management system designed for internal auditors in payment services and corporate environments, following IIA and COSO frameworks. 

## The Problem It Solves
It automates and secures the entire internal audit lifecycle, risk assessment, compliance, correspondence, and integrity management, replacing dispersed and non-secure manual processes. By running entirely on-premises, it ensures strict privacy, compliance, and data confidentiality without relying on cloud services.

## Target User
Internal auditors, compliance officers, risk managers, and system administrators within corporate environments (especially in payment services or banking sectors) who need a secure, local, and regulated environment to manage their operations.

## Current Stage
Production-ready (stable stage). All cloud dependencies have been removed, making it fully ready for local on-premises deployment.

## Tech Stack
- **Frontend:** React with Vite, Tailwind CSS, Lucide React (Icons).
- **Backend:** Express.js (Node.js) with TypeScript.
- **Database:** PostgreSQL for production, and ElectricSQL Pglite embedded for local isolated testing without servers.
- **Hosting / Environment:** On-Premises (Local servers) running without internet dependency.
